01 / Requirements

Platform baseline

CMSWordPress 6.6 or newer
RuntimePHP 8.1 or newer
PresentationDivi 5 parent theme
CommerceWooCommerce

Boundless Artist Core owns structured artist content and Artist HQ. The child theme owns frontend behavior while native Divi 5 layouts remain editable by the site owner. WooCommerce remains authoritative for products, customers, orders, payments, tax, and checkout.

02 / Master Tour Manager

Recommended operating flow

  1. 1
    Create the private tour

    Set the date range, planning status, home base, and working timezone. No public Show is created.

  2. 2
    Advance the booking

    Track inquiry, holds, contacts, offer, deposit, balance, settlement, and internal notes.

  3. 3
    Build the day

    Apply club, festival, travel, rehearsal, press, or off-day templates, then replace estimates with confirmed times.

  4. 4
    Assign the work

    Give tasks an owner, due date, priority, status, tour, and booking context.

  5. 5
    Share the minimum

    Generate revocable calendar or day-sheet links. Keep private money, contacts, notes, and documents in Artist HQ.

  6. 6
    Create a Show draft intentionally

    Only a confirmed, authorized booking action can create a Core Show draft. Publication is never automatic.

Deactivation preserves operations.

Tour records and protected files are removed only through an explicit plugin deletion. Back up both the database and protected document directory before uninstalling.

03 / Merch fulfillment

Measure first. Charge once.

Every physical product needs its packed weight and outside dimensions, or an explicitly reviewed carrier default. The fulfillment origin must be one complete, internally consistent sender address.

USPS

Domestic and international rates, labels, customs documents, tracking, voids and refunds, returns, SCAN forms, and pickups require approved account capabilities.

UPS

Rates, U.S. and Puerto Rico address validation, domestic labels, declared value, tracking, voids, and domestic return drafts use the configured UPS account.

Unknown carrier outcome: inspect the carrier account before retrying. Never submit a potentially billable action twice because a browser timed out.

04 / Privacy boundary

Public facts are not private operations.

Public fan experiencePrivate Artist HQ
Show date, venue, tickets, public price noteOffers, deposits, balances, commissions
Music, members, videos, press, journalPromoter, agent, production, emergency contacts
Products, cart, checkout, customer accountTravel confirmations, room assignments, internal notes
Published booking/contact pageContracts, riders, settlements, receipts

Tour Manager post types are private, not publicly queryable, and excluded from the public REST API. Shared day sheets and calendar feeds use revocable opaque tokens and intentionally omit financial and sensitive contact data.

05 / Licensed updates

Verified before installation

Versioned source Release gates Protected vendor package Licensed site
  • WordPress displays the native plugin update row and a prominent administrator notice.
  • Download URLs are short-lived and bound to an active license and site.
  • The installer verifies the SHA-256 package checksum after download and before installation.
  • Minimum Core compatibility is checked before the install action is offered.
  • Published versions are immutable; corrections ship as a newer version.

06 / Release acceptance

Public means the whole path passes.

A production release requires more than a clean build. Anonymous desktop and mobile journeys, keyboard navigation, responsive layouts, checkout visibility, live shipping, one authorized payment and refund, update delivery, role isolation, protected files, backup restore, and cleanup must all be accepted together.
